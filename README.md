 AI Tools Lab
 
A simple Python project containing sorting algorithms and utility functions,
created for the Artificial Intelligence Tools and Applications Lab.
 
## Project Description
AI Tools Lab demonstrates basic Python programming with Git and GitHub.
It currently contains:
- sorting.py - a bubble sort implementation
- utils.py - utility functions: is_palindrome, count_words and
  celsius_to_fahrenheit
 
## Installation
1. Make sure Python 3 is installed.
2. Clone the repository:
   git clone https://github.com/prabhk2507-glitch/ai-tools-lab.git
3. Move into the project folder:
   cd ai-tools-lab
No external libraries are required.
 
## Usage
 
### Bubble sort
    python sorting.py
    # Output: [1, 2, 3, 5, 8]
 
### Utility functions
    from utils import is_palindrome, count_words, celsius_to_fahrenheit
 
    print(is_palindrome("madam"))              # True
    print(count_words("I love Python"))        # 3
    print(celsius_to_fahrenheit(0))            # 32.0
